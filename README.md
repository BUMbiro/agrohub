## 🌾 АгроХаб – интернет-магазин сельхозпродукции

**АгроХаб** – это учебный интернет-магазин на **Django**, созданный для закрепления навыков веб-разработки.  
Проект включает каталог товаров (семена, удобрения, агрохимикаты, инструменты, техника, саженцы), новости фермеров и 
форму обратной связи.

---

## 🚀 Основной функционал

- **Категории товаров** – семена, удобрения, агрохимикаты, садовый инвентарь, электроинструменты, мини-техника, 
системы орошения, саженцы.
- **Список товаров** в каждой категории с эмодзи-иконками, ценой и единицей измерения (кг, л, м, шт.).
- **Детальная страница товара** – описание, цена, наличие.
- **Новости фермеров** – приземлённые новости из жизни агробизнеса с датами по сезонам.
- **Контакты** – форма обратной связи с выводом данных в консоль и карта Астрахани.
- **Админка Django** – управление товарами, категориями и новостями.

---

## 🛠 Технологический стек

- **Python 3.12** – язык программирования.
- **Django 5.1+** – веб-фреймворк.
- **SQLite** – база данных (для разработки).
- **Bootstrap 5** – стилизация и адаптивность.
- **Эмодзи** – для иконок товаров (работают без внешних библиотек).
- **Pillow** – работа с изображениями (опционально).

## 📦 Установка и запуск

### 1. Клонируйте репозиторий:

```bash
git clone https://github.com/ваш-логин/agrohub.git
cd agrohub
```
### 2. Создайте и активируйте виртуальное окружение:

```bash
python -m venv .venv
.venv\Scripts\activate      # Windows
# source .venv/bin/activate  # macOS/Linux
```

### 3. Установите зависимости:

```bash
pip install -r requirements.txt
```

### 4. Выполните миграции базы данных:

```bash
python manage.py makemigrations
python manage.py migrate
```

### 5. Создайте суперпользователя для доступа в админку:

```bash
python manage.py createsuperuser
```

### 6. Наполните базу тестовыми данными (категории, товары, новости).
**Войдите в shell:**

```bash
python manage.py shell
```
И вставьте код для создания данных (предоставлен в репозитории или в инструкции).

### 7. Запустите сервер:

```bash
python manage.py runserver
```

Откройте браузер по адресу:
## 👉 http://127.0.0.1:8000/

## 🧪 Проверка работы форм
На странице /contacts/ доступна форма обратной связи.
При отправке заполненных данных они выводятся в консоль сервера, а пользователь видит сообщение об успешной отправке.

**Пример вывода в консоли:**

```text
Имя: Иван, Email: ivan@mail.ru, Сообщение: Здравствуйте!
```
