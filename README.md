## 🚀 Основной функционал

- **Категории товаров** – семена, удобрения, агрохимикаты, садовый инвентарь, электроинструменты, мини-техника, 
системы орошения, саженцы.
- **Список товаров** в каждой категории с эмодзи-иконками, ценой и единицей измерения (кг, л, м, шт.).
- **Детальная страница товара** – описание, цена, наличие.
- **Новости фермеров** – приземлённые новости из жизни агробизнеса с датами по сезонам.
- **Контакты** – форма обратной связи с выводом данных в консоль и карта Астрахани. Данные организации 
подтягиваются из модели `Contact` (заполняется через админку).
- **Админка Django** – управление товарами, категориями, новостями и контактами. Настроены списки, фильтры и поиск.
- **Кастомная команда `load_test_data`** – очищает БД и загружает тестовые данные из фикстур.
- **Вывод последних 5 продуктов в консоль** при загрузке главной страницы (для отладки).

## 🛠 Технологический стек

- **Python 3.12** – язык программирования.
- **Django 6.1.1** – веб-фреймворк.
- **PostgreSQL 17** – база данных (через `psycopg2-binary`).
- **python-dotenv** – чтение настроек из `.env` (в зависимостях).
- **Bootstrap 5** – стилизация и адаптивность.
- **Эмодзи** – для иконок товаров (работают без внешних библиотек).
- **Pillow** – работа с изображениями (ImageField в моделях).
- **IPython** – удобная оболочка для `manage.py shell`.

## 📦 Установка и запуск

### 1. Клонируйте репозиторий:

```bash
git clone https://github.com/BUMbiro/agrohub.git
cd agrohub
```
### 2. Создайте и активируйте виртуальное окружение:
```bash
python -m venv .venv
.venv\Scripts\activate      # Windows
# source .venv/bin/activate  # macOS/Linux
```
### 3. Установите зависимости:
```bash
pip install -r requirements.txt
```
### 4. Создайте базу данных PostgreSQL
В `psql` под суперпользователем `postgres`:

```sql
CREATE USER agrohub_user WITH PASSWORD 'ваш_пароль';
ALTER USER agrohub_user CREATEDB;
CREATE DATABASE agrohub WITH OWNER = agrohub_user ENCODING = 'UTF8';
```
### 5. Настройте переменные окружения
Скопируйте .env.template в .env и заполните своими значениями:

```bash
cp .env.template .env    # Windows: copy .env.template .env
```
Пример содержимого `.env`:

```env
SECRET_KEY=ваш_секретный_ключ
DEBUG=True

DB_NAME=agrohub
DB_USER=agrohub_user
DB_PASSWORD=ваш_пароль
DB_HOST=localhost
DB_PORT=5432
```
>`.env` добавлен в `.gitignore` — реальные пароли в репозиторий не попадают.
>В `.env.template` только заглушки.

### 6. Выполните миграции базы данных:
```bash
python manage.py migrate
```
### 7. Создайте суперпользователя для доступа в админку:
```bash
python manage.py createsuperuser
```
### 8. Наполните базу тестовыми данными
**Есть два способа.**

**Способ А** — кастомная команда (рекомендуется):

```bash
python manage.py load_test_data
```
Команда удалит старые данные и загрузит категории и продукты из фикстур `catalog/fixtures/`.

**Способ Б** — вручную через loaddata:

```bash
python manage.py loaddata catalog/fixtures/categories.json
python manage.py loaddata catalog/fixtures/products.json
```
### 9. Запустите сервер:
```bash
python manage.py runserver
```
Откройте браузер по адресу:

## 👉 http://127.0.0.1:8000/

## 🗄 Модели
`Category – name, slug, description.` Описывает категорию товаров.

`Product – category (FK → Category), name, slug, description, price, unit,
image, in_stock, created_at, updated_at.` Товар в каталоге.

`News – title, content, date, image.` Новости фермеров на главной.

`Contact – name, address, phone, email.` Контактные данные магазина.

Для всех моделей заданы `Meta (verbose_name, verbose_name_plural)` и метод `__str__`.

## 🧪 Проверка работы форм
На странице `/contacts/` доступна форма обратной связи.
При отправке заполненных данных они выводятся в консоль сервера, а пользователь видит сообщение об успешной отправке.

Пример вывода в консоли:

```text
Имя: Иван, Email: ivan@mail.ru, Сообщение: Здравствуйте!
```
